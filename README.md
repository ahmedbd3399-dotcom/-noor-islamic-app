# نُور — تطبيق إسلامي شامل

نسخة PWA عربية تعمل على الهاتف ويمكن تحويلها إلى APK/AAB.

## المزايا الموجودة
- مواقيت الصلاة حسب الموقع مع طريقة الحساب المصرية كخيار افتراضي.
- التاريخ الهجري.
- القرآن الكريم 114 سورة.
- عرض الآيات بالرسم العثماني.
- تشغيل التلاوة للآية.
- حفظ آخر آية محفوظة محليًا.
- أذكار وسبحة.
- اتجاه القبلة.
- أسماء الله الحسنى.
- وضع ليلي.
- PWA وService Worker.

## مصادر البيانات
مواقيت الصلاة والقبلة والتاريخ الهجري: AlAdhan API.
القرآن والنص والتلاوة: Al Quran Cloud وCDN.

## التشغيل
افتح المشروع عبر خادم HTTPS/localhost، لأن بعض ميزات PWA والموقع تحتاج سياقًا آمنًا. مثال: GitHub Pages أو أي استضافة ثابتة.

## ملاحظات
هذه نسخة أولى كاملة قابلة للبناء وليست مجرد تصميم. قبل النشر العام، راجع محتوى الأذكار والأحاديث ومصادر الصوت والترخيص وسياسة الخصوصية.
